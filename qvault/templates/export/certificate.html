Custody is the difference between evidence and record. A device signature was made by a key generated on the signer's own hardware that the Q-Vault server has never held — so not even a compromised server could have produced it. A server signature was made by a key this server unwrapped with the signer's password: genuine and attributable, but the server had the means to produce it.

A chained log stops entries being edited. It does not by itself stop the whole log being replaced with a different, internally consistent one — which is what an independent witness co-signature rules out, because the witness saw an earlier state and will not vouch for a substitute.

How to check this yourself

This certificate is for reading. It proves nothing on its own — a certificate is only ever a claim about a document, and this one could have been typed by anybody.

The evidence is decision.json, in the same folder. To check it, open verifier.html in any browser and load decision.json into it. No internet connection, no account and no installation are required, and it does not contact this server.

The verifier rebuilds the payload hash from the decision's own contents and checks every signature against the public keys in the file. Edit one character of the action text in decision.json, reload it, and watch the signatures fail — that is the property being demonstrated.
