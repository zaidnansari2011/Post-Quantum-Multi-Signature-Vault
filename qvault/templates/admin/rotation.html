{# --- The custody boundary, stated plainly ------------------------------------------------- #}
Server-custodied · rotates automatically

The SYSTEM anchor key and each vault's ML-KEM key are wrapped under the server master key, so the scheduler can replace them without a human present. Old anchors keep verifying under the retained key, and every stored file pins the key that encapsulated it — so rotation can never strand a file.

User-custodied · flagged only

A user's signing key is wrapped under a key derived from their password, which the server never holds. It therefore cannot be rotated unattended — the job flags it, and the owner re-issues it from their dashboard. That limitation is the security property working.
