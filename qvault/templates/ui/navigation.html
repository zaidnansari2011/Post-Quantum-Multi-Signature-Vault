{# Page-level navigation (styles: components.css, "tabs", "page header", and the shell's crumbs). tabs(items, current, label) Tabs routed in the URL (?tab=...): each tab is a link, so back, reload and a shared link all land on the same tab, and the page works without JavaScript. items is a list of dicts with key, label, href and optionally count. The current tab has aria-current="page". label names the strip for screen readers ("Vault sections"). page_header(title, description=None, status=None, facts=[], action=None) The top of a screen: the title with its status trailing it, an optional one-line description, a meta line of labelled facts, and at most one primary action. status markup from ui/status.html, e.g. status('approved'). facts a list of (label, value) pairs, rendered as a description list ("Rule: Any 2 of 3"), never as a " · " chain. A value may be markup. action one dict {label, href} for a link, or a caller() block for anything else (a form with a button). Secondary actions belong in the page body or a menu, not here. breadcrumbs(items) items is a list of (label, href) pairs; the last is the current page and its href is ignored. #} {% from "ui/buttons.html" import button %} {% macro tabs(items, current, label) -%}
