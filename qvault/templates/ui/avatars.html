{# Avatars (styles: components.css, "avatars"). A person is a round initial; there are no photos. avatar(name, size=24, decorative=False, entity=False) name the person's display name (or email); the first letter is drawn. size 20, 24 or 32. decorative True when the name is already written beside it, so it is not read twice. entity True for something that is not a person (a vault, a workspace, its treasury): drawn square, so a system action never passes for a person's (screens.md A.7). avatar_stack(names, max=3, size=24) Up to max avatars overlapping, then "+N".
