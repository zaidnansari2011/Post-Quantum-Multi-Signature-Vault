{# Avatars (styles: components.css, "avatars"). A person is a round initial; there are no photos. avatar(name, size=24, decorative=False) name the person's display name (or email); the first letter is drawn. size 20, 24 or 32. decorative True when the name is already written beside it, so it is not read twice. avatar_stack(names, max=3, size=24) Up to max avatars overlapping, then "+N". Read as one list of the names. #} {% macro avatar(name, size=24, decorative=False) -%} {{ ui_initials(name) }} {%- endmacro %} {% macro avatar_stack(names, max=3, size=24) -%} {%- set names = names|list -%} {%- for name in names[:max] %}{{ avatar(name, size, decorative=True) }}{% endfor -%} {%- if names|length > max %}+{{ names|length - max }}{% endif -%} {%- endmacro %}
