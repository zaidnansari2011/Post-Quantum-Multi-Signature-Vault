Using it

Creating a workspace here costs nothing, and nothing asks for a card. There is no service-level agreement: this deployment is run by the project team, on one server, and may be reset as the project changes.

Running your own

The source is public to read. It has no open-source licence yet, so ask the team before you run your own copy.

Single sign-on and provisioning

Single sign-on (SAML, OIDC) and SCIM provisioning aren't built. If your organisation would need them, open an issue on the source repository and say what for.
